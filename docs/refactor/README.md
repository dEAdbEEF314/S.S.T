# リファクタリング作業者向け指示書

このディレクトリの5文書は、承認済みの [REFACTORING_PLAN.md](../REFACTORING_PLAN.md) を5人で分担して実行するための作業指示書です。

## 作業順序

1. `01_baseline_unused.md` を最初に実施する。
2. `02_configuration.md` は、01の基線確定後に実施する。
3. `03_processing_split.md` と `04_llm_split.md` は、01の契約テストを前提に並行実施できる。ただし同じファイルを変更しない。
4. `05_documentation.md` は、01〜04の調査結果を受け取って最終更新する。

## 全員共通の不変条件

- STEAMを構造の正本とする。
- 未割当、欠落、範囲外slot、音声異常、Preflight不一致をArchiveへ昇格させない。
- LLMにタグ値を創作させない。
- 実データ、実ログ、キャッシュ、音源、秘密情報をテストfixtureへコピーしない。
- `data/`、`logs/`、`output/`、`sst-work/` の実体を削除・変更しない。
- 現在変更されている `GEMINI.md` を上書きしない。
- 互換性を壊す場合は、先にshim・警告・移行記録を追加する。
- コマンドはリポジトリ指示に従い `uv run ...` を使用する。

## 共通の完了報告

各担当者は、担当文書のチェックリストに加えて次を報告する。

- 変更ファイル一覧
- 未解決の候補・判断保留
- 実行した検証コマンドと結果
- 他担当へ渡す契約・依存関係・注意点
