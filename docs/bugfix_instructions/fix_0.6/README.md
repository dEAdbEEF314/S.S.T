# fix_0.6 是正作業指示書一覧

本ディレクトリは、音源ライブラリ全353件の本番運用完了後のフォレンジック監査に基づき策定された、多言語同フォーマットバリアント過剰検知の解消とArchive率改善のための作業指示書群です。

## 指示書一覧

| 指示書 | タイトル | 主な対象 AppID | 改善見込み |
| :--- | :--- | :--- | :--- |
| **01** | 多言語同フォーマットバリアント（FLAC/WAV）のスロット競合誤判定防止 | Capcom Arcade Stadium Mini-Album 15件 (`1611240` 等), デススマイルズ (`1971340`) | Archive 16件増（Archive率 92.6% → 97.2%） |

## 共通設計原則

1. **Steam 構造正本性**: Steam スロット構造を絶対の正とし、本編スロット充足（adopted == expected）を前提とする。
2. **検証強度の完全維持**: 確信度閾値の引き下げや、重複チェック・スロット整合性検査の形骸化・緩和は一切行わない。
3. **他スロット非衝突の厳格担保**: 同一フォーマット多言語音源の競合除外は、同一トラック番号（`same_slot_num`）、再生時間差1.5秒以下（`dur_diff <= 1.5s`）、およびアルバム内他スロット公式タイトルとの非競合（`not has_cross_slot_conflict`）を満たす場合に限定する。
