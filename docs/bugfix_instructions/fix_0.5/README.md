## 安全境界と検証強度維持原則

1. **検証強度の維持**: `ResultValidator` の信頼度・品質閾値（`confidence` / `data_quality`）、重複検知、クロススロット整合性検査は一切緩和しない。
2. **STEAM 正本の絶対性**: Steam ストアトラックリストの構造を唯一の正本とし、ローカル推論による Steam スロットの上書きは行わない。
3. **物理エラーの正当性**: FLAC デコードエラー等の真の物理破損（457840, 459851, 1270860）や余剰ボーナス/SE混入（1553350, 1806720, 1299740, 584382）は Review を維持する。
